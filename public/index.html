VISIT NOTICE

موافقة تسجيل بيانات الزيارة

فتح الرابط لا يعني بدء التسجيل. اقرأ المعلومات التالية ثم اختر الموافقة أو الرفض.

ما الذي سيُسجّل إذا وافقت؟
  • عنوان IP بصيغة محجوبة داخل سجل NARD، مع استخدامه مؤقتاً للحصول على الدولة والمحافظة/المنطقة والمدينة التقريبية.
  • العلم، ومزود الإنترنت، واسم المؤسسة، ورقم ASN ونوع الاتصال إذا توفرت من قاعدة بيانات IP.
  • المتصفح ونظام التشغيل ونوع الجهاز، ولغة المتصفح والمنطقة الزمنية وفئة حجم الشاشة.
  • وقت الزيارة واسم نطاق الصفحة المُحيلة فقط، دون مساراتها أو معاملات الرابط.

لإثراء بيانات IP، يُرسل عنوان IP إلى مزود خارجي هو ipwho.is. قد تكون بيانات المدينة والمحافظة غير دقيقة ولا تكشف الحي أو عنوان المنزل. لا يجمع NARD إحداثيات GPS أو يتابع الحركة بعد الزيارة، ولا يقرأ الملفات أو جهات الاتصال أو رقم الهاتف. لا يُحفظ عنوان IP الكامل في سجل NARD. بيانات الجلسة مؤقتة وتُحذف عند انتهاء الرابط أو إيقافه.

بانتظار اختيارك. لن تُرسل بيانات الزيارة قبل الموافقة.
